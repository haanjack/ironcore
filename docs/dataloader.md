# Dataloader

## Task types and collator modes

`UniversalCollator` in `ironcore/dataloader/collator.py` supports four modes that correspond directly to `data.task_type`:

| `task_type` | Collator mode | What it returns |
|---|---|---|
| `pretrain` | `pretrain` | `input_ids`, `labels` |
| `sft` | `sft` | `input_ids`, `labels`, `position_ids`, optionally `cu_seqlens` |
| `dpo` | `dpo` | `chosen_*` and `rejected_*` prefixed copies of SFT output |
| `grpo` | `grpo` | `input_ids`, `attention_mask`, `metadata` list |

**FIM is a preprocessing feature, not a collator mode.** FIM tokens are inserted during data preprocessing via `ironcore/preprocessing/serializer.py`. At training time the collator treats FIM-transformed sequences as ordinary pretrain sequences. Set `data.fim_rate > 0` to enable FIM during preprocessing.

## Dataset classes

### `StreamingDataset` (`ironcore/dataloader/dataset.py`)

Block-based shuffling with O(1) memory footprint. Supports weighted mixing of multiple datasets — the `ratio` field in each `DatasetConfig` determines sampling weight during mixing. Suitable for large text corpora that cannot be fully loaded into memory.

### `StreamingBinaryDataset` (`ironcore/dataloader/dataset.py`)

Memory-mapped access to preprocessed `.bin`/`.idx` files. The `.idx` file contains byte offsets; the `.bin` file contains token IDs as raw integers. Random-access with no memory overhead.

## Collation details

### Pretrain

Sequences arrive pre-tokenized to `seq_length + 1` tokens. The collator stacks them into a batch and shifts by one:
- `input_ids = tokens[:, :-1]`
- `labels = tokens[:, 1:]`

### SFT — bin-packing

Implements First-Fit Decreasing (FFD) bin-packing to maximize GPU utilization:

1. Sort samples by length (descending).
2. Greedily place each sample into the first bin with enough remaining space.
3. Samples within the same bin are concatenated with per-sample `position_ids` that reset to `[0, 1, 2, …]` for each sample (rather than continuing from the previous sample's end position).
4. User prompt tokens are masked in `labels` via `mask_ranges` metadata (set to `-100`).

When `use_flash_attention: true`, the collator outputs `cu_seqlens` — a list of cumulative sequence length tensors per batch element — which FlashAttention uses to apply block-diagonal attention (each packed sample attends only to itself).

### DPO

Runs `_collate_sft()` separately on chosen and rejected samples, then prefixes all keys:
- `chosen_input_ids`, `chosen_labels`, `chosen_position_ids`, `chosen_cu_seqlens`
- `rejected_input_ids`, `rejected_labels`, `rejected_position_ids`, `rejected_cu_seqlens`

Samples are identified as chosen/rejected via `metadata["type"]` (`"dpo_chosen"` / `"dpo_rejected"`).

### GRPO

Returns prompts padded/truncated to `max_seq_len` plus a `metadata` list of dicts. Each metadata dict can contain fields such as `answer`, `test_cases`, `type`, `difficulty`, etc. — used by reward functions during scoring. Completions are generated by the trainer, not the collator.

## Multi-dataset mixing

Multiple datasets can be specified in `data.datasets`. Each dataset entry has a `ratio` field; the `StreamingDataset` mixer samples proportionally to these weights.

## Column mapping

Configure which columns in a dataset correspond to which roles:

| Config field | Default | Used by |
|---|---|---|
| `text_column` | `"text"` | Pretrain |
| `messages_column` | `"messages"` | SFT |
| `chosen_column` | `"chosen"` | DPO |
| `rejected_column` | `"rejected"` | DPO |
| `prompt_column` | `"prompt"` | GRPO |
| `answer_column` | `"answer"` | GRPO |

## FIM preprocessing

Fill-in-the-Middle is applied at preprocessing time, not during data loading:

| Config field | Default | Description |
|---|---|---|
| `data.fim_rate` | `0.0` | Fraction of pretrain documents to transform (0 = disabled) |
| `data.fim_split_type` | `"random"` | `"random"` or `"line_aware"` split strategy |
| `data.fim_prefix_token` | `"<fim_prefix>"` | PSM format prefix sentinel |
| `data.fim_suffix_token` | `"<fim_suffix>"` | PSM format suffix sentinel |
| `data.fim_middle_token` | `"<fim_middle>"` | PSM format middle sentinel |

## Configuration reference

| Field | Default | Description |
|---|---|---|
| `data.task_type` | `"pretrain"` | Determines collator mode |
| `data.seq_length` | `1024` | Sequence length |
| `data.tokenizer_type` | `"bbpe"` | `"bbpe"`, `"tiktoken"`, or `"sentencepiece"` |
| `data.pad_token_id` | `null` | Padding token (null = use EOS) |
| `data.vocab_name_or_path` | `"gpt2"` | Tokenizer vocab name or path |
| Dataset `ratio` | `1.0` | Sampling weight for this dataset |
